#### Definition of `serviceWorker.js`:
serviceWorker.js is a JavaScript file that runs in the background to cache your app files in Cache Storage and intercept network traffic. In this way the web app can support offline fallback and be installable on any kind of device.
#### Definition of `manifest.json`:
manifest.json is a JSON file that provided the browser with the app metadata like the app's name,starting page, standalone display mode etc. In this way your app can be successfully installed and launched as a native app.
